# Xtobe Business vs. Hiring a Content Creator / Media Agency

## The clinic's real choice (Dubai, 2026)

### Option A — Hire in-house content creator
| Item | Cost/month |
|------|-----------|
| Junior content creator salary (Dubai) | AED 4,000–6,000 |
| Visa + insurance + benefits | ~AED 1,000 |
| Equipment (phone/gimbal/lights) amortized | ~AED 300 |
| Editing software + tools | ~AED 200 |
| **Total** | **AED 5,500–7,500/month** |
| Output | ~8–12 posts/month, one person, sick days, notice period |
| Consistency | Depends on one employee leaving |

### Option B — Media agency retainer
| Item | Cost/month |
|------|-----------|
| Typical Dubai agency retainer (social only) | AED 3,500–10,000 |
| Campaign/ads budget (extra) | AED 2,000+ |
| **Total** | **AED 5,500–12,000/month** |
| Output | 12–20 posts/month, slow turnaround (3–7 days per request) |
| Extra video/edit | AED 300–800 each |

### Option C — Xtobe Business (Elite)
| Item | Cost/month |
|------|-----------|
| Xtobe Elite subscription | **AED 1,999** |
| Everything included: inbox, bookings, AI content, 20 AI videos | AED 0 extra |
| **Total** | **AED 1,999/month** |
| Output | Unlimited messages answered + 20 AI videos + daily posts possible |
| Turnaround | 2 minutes per video. Any staff member. No hiring, no waiting. |
